## Contenido

- `avance1/`: los cuatro programas en Python (ejercicios 1 a 4).
- documento PDF, diagramas de flujo (.png y .drawio).

## Cómo ejecutar los programas

1. Instalar Python 3 y abrir la carpeta del proyecto en Visual Studio Code.
2. Abrir una terminal en la carpeta `avance1/`.
3. Ejecutar el programa deseado
4. Ingresar los datos que solicita el programa, uno por uno, y presionar Enter después de cada uno.
